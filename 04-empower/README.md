## מרכז ההדרכה (אינטראקטיבי)

**[levi-garage.co.il/training](https://levi-garage.co.il/training)**: אותם מסכים כמו במדריכים, ועל כל כפתור נקודה ממוספרת שמסבירה מה הוא עושה ומה קורה אחריו. שני מסלולים (לבעלים ולמנהל העבודה, ולעובדים), ובכל מסך גם הסרטון שמתחיל בפרק שלו. סיור מודרך, חיפוש, ו**"שאלה על המערכת"**: בוט שעונה מתוך המדריך ומקפיץ לכפתור הנכון. התוכן ב-[levi-garage/lib/training/guide.ts](../levi-garage/lib/training/guide.ts).

**בהמשך:** סרטוני ההדרכה, באותו עמוד, עם אינדקס פרקים: לחיצה קופצת לחלק, והחלק הנוכחי מסומן. סרטון השיווק נפרד (הוא לא הדרכה).

> **הצילומים במדריכים** צולמו מהמערכת החיה, בתרחיש הדגמה עם שמות בדויים, שנמחק אחרי הצילום. הם נוצרים בסקריפט ([capture/](capture/)): יום עבודה שלם נבנה במסד, כל מסך מצולם, והכול נמחק בסוף. מסך שהשתנה? `npm run capture` מתוך `04-empower/capture`, או רק תמונה אחת: `npm run capture -- m8`. הסקריפט רושם גם את המיקום של כל כפתור (`guides/hotspots.json`), ואז `node scripts/sync-training.mjs` (מתוך levi-garage) מעדכן את מרכז ההדרכה.
