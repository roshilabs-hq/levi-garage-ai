## בהמשך

- סרטוני הדרכה: מכונאי · דניאל ואבי · שיווק. כל אחד ביוטיוב עם פרקים, ובאפליקציה טאב "הדרכה" שמקפיץ לפרק.

> **הצילומים במדריכים** צולמו מהמערכת החיה, בתרחיש הדגמה עם שמות בדויים, שנמחק אחרי הצילום.
