## Build vs Buy
Custom GPT דורש ChatGPT Plus (כ-$20) **לכל עובד**. **Gem משותף בקישור, ולצוות לא עולה כלום.** בנוסף, Gemini חזק בהבנת קול ותמונה, וזה מה שהמכונאים שולחים.
